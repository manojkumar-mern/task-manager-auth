# Task Manager – Auth System ✅

A full-stack **Task Manager application with Authentication** built using the **MERN stack**.  
This project includes secure login/signup, JWT-based authentication, protected routes, and task management features.

---

## Features

### Authentication
- User Signup & Login
- JWT token-based authentication
- Token stored securely in `localStorage`
- Logout functionality
- Protected routes (Dashboard access blocked without login)
- Forgot Password & Reset Password flow

### 🧾 Task Management
- Add tasks with title & description
- Set priority and due date
- Mark tasks as completed / pending
- Filter & search tasks
- Dashboard with task stats
